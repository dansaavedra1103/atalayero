# Data

Everything in this directory except this README is ignored by git and disposable:
`make ingest` rebuilds it from scratch.

## Source

*IBM Transactions for Anti Money Laundering (AML)*, HI-Small variant, Kaggle dataset version 8,
by Erik Altman. Synthetic data generated by a multi-agent simulation: no real people or institutions.
License: CDLA-Sharing-1.0 (attribution and license text in [`tests/fixtures/`](../tests/fixtures/README.md)).

| File | Size | Content |
| --- | --- | --- |
| `HI-Small_Trans.csv` | 475,664,283 bytes | 5,078,345 transactions, 5,177 labelled as laundering |
| `HI-Small_Patterns.txt` | 323,844 bytes | 370 laundering attempts in 8 typologies (ground truth for later phases) |

`make ingest` downloads both files anonymously over HTTPS from Kaggle's public endpoint (no account
or token) and verifies their SHA-256. URL, dataset version and checksums live in
[`config/settings.yaml`](../config/settings.yaml). Files already present with the right checksum
are not downloaded again, so a manual download from the Kaggle page into `data/raw/` also works.

## Layout after `make ingest`

```
data/
├── raw/
│   ├── HI-Small_Trans.csv      # source file
│   ├── HI-Small_Patterns.txt   # source file (not parsed yet)
│   └── transactions.parquet    # typed transactions + transaction_id
└── atalayero.duckdb            # table raw.transactions, loaded from the Parquet file
```

## `raw.transactions`

| Column | Type | Notes |
| --- | --- | --- |
| `transaction_id` | BIGINT | 1-based row number in the source file (ADR-0001) |
| `timestamp` | TIMESTAMP | Minute resolution; the source file is not sorted by time |
| `from_bank`, `to_bank` | VARCHAR | Leading zeros are significant (`010` is not `10`) |
| `from_account`, `to_account` | VARCHAR | Hex account IDs |
| `amount_received`, `amount_paid` | DECIMAL(20, 6) | Exact: up to 6 decimals (Bitcoin) and 13 integer digits |
| `receiving_currency`, `payment_currency` | VARCHAR | |
| `payment_format` | VARCHAR | Cheque, Credit Card, ACH, Cash, Reinvestment, Wire, Bitcoin |
| `is_laundering` | BOOLEAN | Source label |
